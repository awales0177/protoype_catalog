Toolkit localStorage → JSON

Reads browser localStorage keys written by the legacy toolkit UI (toolkit_*, toolkit-reactions-*) and builds a fragment you can merge into toolkit.json under toolkit.toolkits[], then load with api/scripts/upload_data_to_postgres.py (or reconcile with your existing DB rows by matching ids).

Note: Open this file from the same origin as the catalog (e.g. http://localhost:3000/toolkit-export-localstorage.html) so it can read your app’s storage.
